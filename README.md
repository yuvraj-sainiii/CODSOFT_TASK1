# Number Guessing Game 🎮

## About the Project

This project is developed as part of Task 1 of the CodSoft Java Development Internship.

The Number Guessing Game generates a random number between 1 and 100. The user must guess the number within a limited number of attempts.

## Features

* Random number generation
* User input and feedback
* Hints for guesses that are too high or too low
* Limited attempts
* Multiple rounds
* Score calculation
* Input validation

## Technologies Used

* Java
* Java Scanner
* Random class
* Loops and conditional statements

## How to Run

1. Install the Java Development Kit (JDK).

2. Download or clone this repository.

3. Open the project folder in the terminal.

4. Compile the program:

   javac NumberGame.java

5. Run the program:

   java NumberGame
